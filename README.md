# Camera Telemetry Updates

This public repository hosts signed update metadata and release assets for Camera Telemetry.

- `docs/stable/update.json` is the stable-channel manifest published by GitHub Pages.
- Versioned core update ZIP files are published as GitHub Release assets.
- Every update package is verified by SHA-256 and an RSA signature before installation.

Application source code, recordings, customer deliveries, and the signing private key do not belong in this repository.
